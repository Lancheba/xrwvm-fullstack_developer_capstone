# Best Cars Dealership Application

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership Full Stack Application

## Project Description
This project is part of the IBM Full Stack Application Development Capstone Project. It is a full stack car dealership application where users can view dealerships, filter them by state, read dealer reviews and post their own reviews.

## Technologies Used
Python, Django, HTML, CSS, JavaScript, React, Node.js, Express, MongoDB, Flask, Docker
